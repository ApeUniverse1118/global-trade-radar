📖 贸易概念词典

日报里的 CBAM、IOR、de minimis、双反、处理费……这些词到底是什么？这里用大白话讲清楚：一句话懂它、知道为什么和你有关、看清它最近怎么变、明白现在该做什么。读到日报里的生词，点进来就懂。

🗂️ 已收录 26 个核心概念 🎯 随每期日报持续补充

🇺🇸 美国海关与关税

清关、规费、执法
📋

IOR 进口商记录

美国清关的"法律责任人"。9/18 起 CBP 严查，借号、信息不实当场作废、追溯。

 📦

de minimis 小包免税

各国对低值小包的免税额。英美欧同步取消/收紧，低价直邮红利结束。

 🧾

MPF / 清关规费

美国清关按票收的固定处理费，跟货值挂钩、有上下限，报价别漏算。

 ⚖️

301 与 337

301 是美国单方面加关税的大棒；337 查侵权、可直接禁售。

 🗓️

四年法定审查

301 每满四年做法定检查：有合格申请就必须继续，USTR 说了不算。

 📮

邮政入境 Entry Type 13

美国邮政小包"结构化报关"通道，10/22 起受监管货不再走邮政。

🇪🇺 欧盟合规与费用

碳关税、小包、绿色宣称
🌍

CBAM 碳关税

欧盟对进口产品按含碳量补收的"碳税"，正从只申报走向要交钱。

 💶

欧盟小包处理费

进口小包每件多收约 2 欧元、叠加 3 欧关税，平台被认定为法定进口人。

 🧾

申报行

€2 处理费按"申报行"收不是按包裹收：一个包裹 3 种商品 = 收 3 次。

 🤝

自愿出口限制 VER

"自愿"少卖是变相配额，严重违反 WTO；中方已两次拒绝，欧方转向保障措施/配额。

 🌿

GARAN / 反漂绿

"环保、绿色、碳中和"宣称必须有证据，9/27 起禁止漂绿。

 🔖

PID 产品识别码

11/1 起每个进欧盟 B2C 包裹要报商品"身份证号"，笼统品名不再够用。

 🛡️

反胁迫工具 ACI

欧盟的贸易大棒，德法正想改成"默认启动"；还停在草案，先记进观察清单。

 🪪

数字产品护照 DPP

欧盟拟给每件消费品配"电子身份证"：《欧洲产品法》草案拟从电池、纺织品扩到全品类。

 📊

进口晴雨表

欧盟用海关数据自动筛"量增价跌"品类；不加税，但把立案证据成本降到零。

🛡️ 贸易救济与执法

双反、追溯、规避
🥊

反倾销 / 双反

被认为"卖太便宜"或"拿了补贴"就加惩罚性关税，命中率越来越高。

 ⏪

追溯征税

今天的裁决能回头补几个月前已到港货的税，甚至收现金保证金。

 🤝

中美关税休战

对等降税是分阶段、有清单、有截止日的"停火"，不是全面免税。

 📦

关税配额 TRQ / 保障措施

额度内低税、超出加税，常先到先得；英国钢铁、欧盟电工钢都用它。

 🏭

熔炼与浇铸国

10/1 起欧盟钢铁要报钢水在哪国、哪个炉子浇出来，证明不清不放行。

 📋

海关登记

海关先把货登记在案、将来裁决可回头补税；登记期就是风险累积期。

 🔄

日落复审（五年复审）

老关税每五年给一次"要不要取消"的复核机会；不参加=默认维持。

 🧮

混合税

同一商品两段收税：配额内从量、配额外从价。英国对华钛白粉即此结构。

 🕳️

反规避

绕道第三国、微调产品躲双反税？认定规避即拉回原税令、追溯征税。

🚀 商业模式与市场

怎么发货、钱往哪投
🏭

本地仓 vs 直邮

小包被加税查人后，爆款转海外仓、长尾直邮但别再低申报。

 ⚡

英国能源与预算

能源价格上限决定英国家庭开支，秋季预算是政府财政大动作。
